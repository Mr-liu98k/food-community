## 后端新增

| 模块 | 实现要点 |
|---|---|
| 评论（楼中楼） | `comment.parent_id + root_id` 存储；**发评论仅传 parentId**，rootId/replyUserId 由服务端推导（防篡改）；根评论分页 + 每条携带全部子评论（一次 IN 查询再分组）；**删除递归清理所有子孙**（BFS 收集后代 ID）；归属校验 |
| 点赞 | INSERT IGNORE 幂等；`recipe.likes_count` 冗余计数（插入/删除成功才 ±1） |
| 收藏 | 幂等切换；我的收藏分页（JOIN recipe 全字段） |
| 详情状态 | `/api/recipe/{id}` 携带 `liked/favorited`（游客为 false） |
| 作者主页 | `/api/user/{id}/profile`（资料 + 已通过菜谱数）、`/api/user/{id}/recipes`（已通过分页）；探店计数 M3 补 |
| 轮播图 | 管理端 CRUD 强校验**只能关联已通过菜谱**；前台列表 JOIN `recipe.status=1`（菜谱被拒/删除自动下架）；`/api/banner/list` |
| 管理端评论 | 分页 + keyword（内容/昵称）+ 递归删除 |

## 前端新增

- `CommentSection.vue`：楼中楼评论区（发评 / 回复 @ / 删除自己 / 分页 / 空态）
- 菜谱详情：👍 点赞、★ 收藏按钮（乐观更新，未登录引导登录）+ 评论区
- `UserProfileView`：作者主页（资料头 + 达人徽章 + 菜谱网格）
- 我的收藏 / 我的评论页；用户下拉菜单扩充
- 首页 `el-carousel` 轮播（点击跳关联菜谱详情；无图走暖色渐变横幅）
- 管理端：评论管理页、轮播图管理页（选菜谱弹窗仅列已通过菜谱）
- 导航/路由/菜单同步

## 浏览器体验路径

1. 详情页对演示菜谱点 👍 / ★（会提示登录）→ 收藏后进「我的收藏」
2. 评论区发根评论 → 换账号回复 → 出现「回复 @xxx」楼中楼
3. 删除自己的评论 → 其下回复一起消失
4. admin 登录 → 信息管理 → 评论信息 / 轮播图信息（新增轮播时选已通过菜谱，首页立即出现）
