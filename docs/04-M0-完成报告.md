## 本机运行指南

```bash
# 1. 数据库（已执行过可跳过）
mysql -uroot -p < sql/01_schema.sql

# 2. 后端（端口 8080，凭据读 backend/.env）
cd backend && mvn spring-boot:run

# 3. 前端（端口 5173，代理 /api → 8080）
cd frontend && npm run dev
```

浏览器打开 http://localhost:5173 ：
- 注册一个普通账号 → 进入用户端首页（M1 接入真实内容）
- 用 `admin / admin123` 登录 → 进入管理端看板（M6 接入真实统计）
- 右上角头像 → 个人中心：改资料 / 改密码

## 遗留说明

- 验收脚本 `verify-m0.sh` 因安全审批未通过由你在本机自行运行（预期全绿）。
- JWT 为无状态：改密码不会踢掉旧 token（可接受，答辩可讲）。如需踢下线后续可加 token 版本号。
- 管理员登录后端与用户登录复用同一 `/api/auth/login`，前端按 `role` 分流（用户端 / 管理端双布局已完成）。
