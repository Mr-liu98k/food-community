## 技术方案

| 决策 | 说明 |
|---|---|
| 接入方式 | **Spring AI（1.1.8）openai starter + 阿里云百炼 OpenAI 兼容端点**（DashScope 官方 starter 在 Maven Central 不存在，兼容端点方案更稳） |
| 端点 | `https://dashscope.aliyuncs.com/compatible-mode`（**不能带 /v1**，Spring AI 会自动拼 `/v1/chat/completions`，曾踩 `v1/v1` 双斜杠 404 并已修正） |
| 凭据 | 系统环境变量 `ALIYUN_MAAS_API_KEY` → 已用工具同步进 `backend/.env` 的 `DASHSCOPE_API_KEY`（gitignore，不外泄）；`AI_MODEL` 可换模型（默认 qwen-plus） |
| 缺 Key 容错 | `ObjectProvider<ChatModel>` 注入：无 Key 时后端照常启动，仅 AI 接口返回"未配置"提示（不会崩整个服务） |
| 多轮对话 | 后端无状态：前端携带最近 10 轮 messages，服务端注入"美食专家" system 人设后整体发给模型 |
| 流式 | `ChatModel.stream()` 返回 `Flux<String>`，Controller `produces=text/event-stream` |
| 错误兜底 | 流中异常 → `onErrorResume` 追加一条"回答中断"SSE 帧，前端不白屏 |
| 输入防御 | role 仅收 user/assistant（system 由服务端注入）、单条 ≤2000 字、≤20 条、截断至最近 10 轮 |

## 前端

- `api/ai.js`：基于 fetch + ReadableStream 的 SSE 客户端（逐帧解析 `data:` 前缀，AbortController 支持停止）
- AI 聊天页 `/ai`：
  - 聊天气泡（AI 左 / 用户右）+ Markdown 渲染
  - **逐字流式输出**（光标闪烁提示生成中）+ 停止按钮
  - 多轮追问（历史自动携带）、清空会话、快捷问题 chips、空态欢迎语
- 导航栏「AI 美食专家」入口（登录可见）

## 备注

- 回答为真实大模型生成，可能有误，页面已提示"请自行判断"；system 提示词要求不确定信息如实说明不编造（贴合答辩的 AI 边界意识）。
- 如需省 Key 调用，可改 `.env`：`AI_BASE_URL=http://localhost:11434/v1` + `AI_MODEL=qwen2.5:7b`（本地 Ollama OpenAI 兼容）——代码零改动。
